⚙️ Configuração — AWS Rekognition

Ajusta os thresholds e parâmetros do sistema

🎯 Thresholds de Similaridade
O que faz: Define a percentagem mínima de similaridade para considerar duas faces como a mesma pessoa.
Thresholds separados para Verificação 1:1 e Identificação 1:N — requisitos de segurança diferentes.
AWS Default
80%
Valor padrão da API AWS Rekognition
AWS — Uso Geral
90–95%
Verificação de identidade geral (fonte: AWS docs)
AWS — Alta Segurança
99%+
Autenticação, controlo de acesso (fonte: AWS docs)
Verificação 1:1 (CompareFaces)
Comparação direta entre duas faces — recomendado valor alto (95%+)
—
Identificação 1:N (SearchFacesByImage)
Pesquisa numa coleção — pode ser ligeiramente mais baixo (80–90%)
—
⬆️ Mais alto → menos falsos positivos, pode rejeitar a pessoa certa com má iluminação ou ângulo
⬇️ Mais baixo → aceita mais, mas aumenta risco de aceitar outra pessoa
Fonte: AWS Rekognition — Using similarity thresholds
🎭 Threshold de Face Liveness
O que faz: Define a percentagem mínima de confidence para considerar que a câmara está a ver uma pessoa real (e não uma foto, vídeo ou máscara).
A AWS devolve um score de 0–100: quanto mais alto, mais certo é que é uma pessoa viva.
Mínimo absoluto
50%
Abaixo disto há risco elevado de fraude
Uso geral (recomendado)
75%
Valor padrão AWS — equilíbrio segurança/usabilidade
Alta segurança
≥ 90%
Autenticação crítica — AWS recomenda para contextos sensíveis
Liveness (GetFaceLivenessSessionResults)
Score mínimo para aceitar o desafio como 'pessoa real' — AWS recomenda ≥ 75%
—
⬆️ Mais alto → mais difícil de spoofar, mas pode rejeitar utilizadores legítimos em má iluminação
⬇️ Mais baixo → mais permissivo, aumenta risco de aceitar ataques de apresentação (fotos/vídeos)
Fonte: AWS Rekognition — Face Liveness best practices
As alterações só têm efeito após clicar em 'Guardar'.
