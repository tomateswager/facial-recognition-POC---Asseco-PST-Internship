⚙️ Configuração — DeepFace

Ajusta os thresholds e parâmetros do motor DeepFace

🎯 Thresholds de Distância Cosine
O que faz: Define a distância cosine máxima para considerar duas faces como a mesma pessoa.
Ao contrário da similaridade percentual, aqui valores mais baixos = mais restritivo.
O ArcFace devolve distâncias entre 0 (idêntico) e 2 (completamente diferente). O threshold padrão AWS é 0.68 para ArcFace+Cosine.
ArcFace Default (LFW)
0.68
Threshold padrão do DeepFace para ArcFace+Cosine
POC (recomendado)
0.54
Mais restritivo — menos falsos positivos neste POC
Permissivo
≥ 0.70
Aceita variações maiores de ângulo/iluminação
Verificação 1:1
Comparação direta entre duas faces — recomendado valor mais baixo (mais restritivo)
Usado em: Verificação 1:1 · Pesquisa Vídeo (modo 1:1) · Comparar Motores
—
Identificação 1:N
Pesquisa na base de dados — pode ser ligeiramente mais permissivo
Usado em: Identificação 1:N · Câmara Live · Pesquisa Vídeo (modo 1:N) · Multi-Pessoa
—
Documento ID vs Câmara
Comparação foto de documento vs câmara — mais permissivo porque as condições de foto são muito diferentes
Usado em: Documento ID (verificação face do doc vs câmara ao vivo)
—
⬆️ Mais alto → aceita mais variações, aumenta risco de falsos positivos
⬇️ Mais baixo → mais restritivo, pode rejeitar a pessoa certa em más condições de iluminação ou ângulo
🖼️ Thresholds de Qualidade de Imagem
O que faz: Define os critérios mínimos de qualidade que uma imagem deve cumprir antes de ser processada.
Imagens de baixa qualidade degradam a precisão do reconhecimento facial.
Nitidez mínima (Anti-Blur)
Variância do Laplaciano — valores baixos indicam imagem desfocada. Mínimo recomendado: 30–80
Usado em: Qualidade de Imagem · Verificação 1:1 · Identificação 1:N · Registo · Documento ID
—
⬆️ Mais alto → exige mais nitidez, pode rejeitar fotos razoáveis
⬇️ Mais baixo → aceita imagens levemente desfocadas
Tamanho mínimo da face (px)
Largura e altura mínimas da face detetada em pixels. Mínimo recomendado: 40–80px
Usado em: Qualidade de Imagem · Verificação 1:1 · Identificação 1:N · Registo · Documento ID
—
⬆️ Mais alto → exige face maior na imagem — rejeita fotos tiradas ao longe
⬇️ Mais baixo → aceita faces pequenas com menor qualidade de reconhecimento
As alterações só têm efeito após clicar em 'Guardar'.
